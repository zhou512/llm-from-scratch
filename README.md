# 我的开源项目复现记录

一名大三学生的项目复现仓库。目标：**搞懂原理，而不是跑通别人的代码**。

每个项目目录下都有：

- `README.md` —— 做了什么、怎么跑、结果如何
- `notes/` —— 学习笔记（比代码本身更重要）
- `src/` —— 我自己的实现
- `refs/` —— 参考的原始代码快照（用于对照，不修改）

## 「复现」的强度不一样

这两个项目的**学习强度不同**，我在每个项目的 README 里都写明了阶段划分：

| 强度 | 做什么 | 本项目 |
|---|---|---|
| A. 跑通 | 装环境、跑训练 | — |
| B. 读懂 + 改造 | 逐块读懂、改配置做实验 | ← nanoGPT **阶段 1** |
| C. 从零重写 | 合上参考代码自己实现 | ← micrograd；nanoGPT **阶段 2**（规划中） |

判断标准：**把参考代码删掉，你还能自己写出来吗？**

## 为什么做这些

- 反向传播、Transformer 这些核心概念，**光看论文和教程是学不会的**，必须亲手写一遍

- 全部代码和笔记公开，作为能力的直接证据
