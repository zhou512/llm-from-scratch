# 我的开源项目复现记录

一名大三学生的项目复现仓库。目标：**搞懂原理，而不是跑通别人的代码**。

每个项目目录下都有：

- `README.md` —— 做了什么、怎么跑、结果如何
- `notes/` —— 学习笔记（比代码本身更重要）
- `src/` —— 我自己的实现
- `refs/` —— 参考的原始代码快照（用于对照，不修改）

## 项目列表

| # | 项目 | 状态 | 说明 |
|---|---|---|---|
| 01 | micrograd 复现 | 🚧 进行中 | 从零实现标量级自动求导引擎（~111 行纯 Python，零依赖） |
| 02 | nanoGPT 复现 | ⏳ 计划中 | 在 RTX 4070 8GB 上从零训练字符级 GPT，含中文语料版 |

## 为什么做这些

- 反向传播、Transformer 这些核心概念，**光看论文和教程是学不会的**，必须亲手写一遍
- 复现过程本身就是最好的工程训练：环境、调试、实验记录、版本管理
- 全部代码和笔记公开，作为能力的直接证据
