## 一、四个类，一条继承链

```
Module              基类：定义 parameters() 和 zero_grad()
  ├── Neuron        一个神经元：w 向量 + b 标量
  │     └── (Layer 持有 N 个 Neuron)
  ├── Layer         N 个神经元组成一层
  └── MLP           N 个 Layer 串起来
```

注意 `Layer` **不是**继承 `Neuron`，而是**持有**（has-a）神经元列表。
`MLP` 同理，持有 `Layer` 列表。这就是「组合优于继承」。

---

## 二、`Module` 基类：为什么需要它

```python
class Module:
    def zero_grad(self):
        for p in self.parameters():
            p.grad = 0

    def parameters(self):
        return []
```

两个方法的分工很巧妙：

- **`parameters()` 返回空列表**——基类不知道子类有哪些参数，交给子类重写
- **`zero_grad()` 遍历 `parameters()`**——**只写一次**，所有子类自动继承

这是模板方法模式：基类定义流程，子类填充细节。

### ★ `zero_grad` 为什么必须有

回顾 `test_backward_accumulates_across_calls`：**重复调用 `backward()` 梯度会累加**。

所以训练循环里每一步都必须先清零，否则梯度会越滚越大：

```python
for step in range(steps):
    loss = compute_loss()
    model.zero_grad()        # ★ 必须！否则梯度累积
    loss.backward()
    for p in model.parameters():
        p.data -= lr * p.grad
```

PyTorch 里 `optimizer.zero_grad()` 干的是**同一件事**。

## 三、`Neuron`：三个细节

```python
class Neuron(Module):
    def __init__(self, nin, nonlin=True):
        self.w = [Value(random.uniform(-1, 1)) for _ in range(nin)]
        self.b = Value(0)
        self.nonlin = nonlin

    def __call__(self, x):
        act = sum((wi * xi for wi, xi in zip(self.w, x)), self.b)
        return act.relu() if self.nonlin else act

    def parameters(self):
        return self.w + [self.b]
```

### 细节 1：`sum(..., self.b)` 里的起始值

Python 的 `sum(iterable, start)` 第二个参数是**起始值**。

```python
sum((wi*xi for wi,xi in zip(self.w, x)), self.b)
#   └── 加权和生成器 ────────────────┘   └── 起点是 b
```

等价于 `b + w0*x0 + w1*x1 + ...`。
**如果忘了写 `self.b`，偏置就永远不参与计算**，而且不会报错——静默的 bug。

### 细节 2：权重初始化范围

`random.uniform(-1, 1)`：小随机数。为什么不全初始化成 0？
因为**全 0 会让所有神经元完全相同**（对称性），反向传播后梯度也一样，
网络退化成一个神经元。这叫**对称性破缺**。

### 细节 3：`nonlin` 开关

- `nonlin=True` → 输出经过 ReLU（隐藏层）
- `nonlin=False` → 输出原样（**最后一层**）

**为什么最后一层不要 ReLU？** 因为 SVM loss 需要输出可以是负数
（用来表示「属于负类」）。如果加了 ReLU，所有负值都被截成 0，就学不出负类了。

## 四、`Layer`：一个反直觉的特例

```python
class Layer(Module):
    def __call__(self, x):
        out = [n(x) for n in self.neurons]
        return out[0] if len(out) == 1 else out      # ★
```

**只有 1 个神经元时返回单个 `Value`，而不是 `[Value]`。**

这样设计是为了让最后一层（输出 1 维）直接得到标量，
方便写 `loss = (1 + -y * pred).relu()`。

代价是**返回类型不统一**：调用方得知道这一层有几个神经元。
测试里 `test_layer_single_neuron_returns_scalar` 和
`test_layer_output_length` 就是钉住这个行为的。

> 这是个「实用主义」的取舍。更好的 API 是永远返回列表，
> 由调用方取 `out[0]`。你可以自己试着改一版，看哪些测试会挂。

## 五、`MLP`：`sz` 那个列表技巧

```python
class MLP(Module):
    def __init__(self, nin, nouts):
        sz = [nin] + nouts                                    # ★
        self.layers = [Layer(sz[i], sz[i+1], nonlin=i != len(nouts)-1)
                       for i in range(len(nouts))]
```

以 `MLP(3, [4, 4, 1])` 为例：

```
sz = [3, 4, 4, 1]
      ↑  ↑  ↑  ↑
      输入 隐藏 隐藏 输出

i=0: Layer(3, 4)  nonlin=True    （i != 2）
i=1: Layer(4, 4)  nonlin=True    （i != 2）
i=2: Layer(4, 1)  nonlin=False   （i == 2，最后一层）
```

- **`[nin] + nouts`** 把输入维度拼到前面，这样 `sz[i]` 到 `sz[i+1]` 就是第 i 层的形状
- **`nonlin = i != len(nouts)-1`** 让最后一层自动变成线性层

参数数量算一下：

| 层 | 权重 | 偏置 | 小计 |
|---|---|---|---|
| Layer(3,4) | 4×3 = 12 | 4 | 16 |
| Layer(4,4) | 4×4 = 16 | 4 | 20 |
| Layer(4,1) | 1×4 = 4 | 1 | 5 |
| | | | **41** |

（`test_mlp_parameter_count` 断言的就是 41）

### 前向传播

```python
def __call__(self, x):
    for layer in self.layers:
        x = layer(x)        # 上一层的输出就是下一层的输入
    return x
```

就这么简单——**数据流过一个 Layer 列表**。所有复杂性都在 `Neuron` 里。

### 参数展平

```python
def parameters(self):
    return [p for layer in self.layers for p in layer.parameters()]
```

嵌套列表推导，把「层的参数」摊成一维列表。
训练循环只关心「有哪些参数」，不关心它们属于哪一层。

## 六、完整的前向追踪

输入 `x = [1.0, 2.0, 3.0]`，模型 `MLP(3, [4, 4, 1])`：

```
x                    [Value, Value, Value]        3 个
 ↓ Layer(3,4) 每个神经元做 3 次乘 + 1 次加 + ReLU
h1                   [Value × 4]                  4 个
 ↓ Layer(4,4)
h2                   [Value × 4]                  4 个
 ↓ Layer(4,1)  只有 1 个神经元 → 返回标量，不加 ReLU
out                  Value                        1 个
```

**每一步都只是在做 `Value` 的加法和乘法**，梯度由 `Value._backward` 负责传回去。
`nn.py` 完全没有涉及梯度计算——**它只负责搭结构**。

这就是分层的价值：`engine.py` 管求导，`nn.py` 管结构。

## 七、训练循环的四个动作

```python
loss = svm_loss(model, xs, ys)      # ① 前向 + 算损失
model.zero_grad()                   # ② 清梯度（★ 别忘）
loss.backward()                     # ③ 反向传播
for p in model.parameters():
    p.data -= lr * p.grad           # ④ 更新参数
```

第 ④ 步的细节：**改的是 `p.data`，不是 `p`**。
`p` 是 `Value` 对象，`p.data` 才是那个浮点数。如果写成 `p -= lr * p.grad`，
会把 `p` 变成一个全新的 `Value`，而它不在 `model.parameters()` 里——训练就静默失效了。

### SVM（hinge）损失

```python
loss = sum((1 + -y * pred).relu() for y, pred in zip(ys, preds))
```

- `y` 是 ±1，`pred` 是模型输出
- `1 - y*pred`：分类正确且间隔 ≥1 时 ≤0，ReLU 后为 0（无损失）
- 分类错误时为正，产生损失

配合 `train.py` 里的 L2 正则项，就是完整的最大间隔分类器。
