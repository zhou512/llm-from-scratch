## 一、★ 第一优先：Karpathy 的「Neural Networks: Zero to Hero」

**这是和你的 micrograd 项目 100% 配套的课程**——micrograd 就是这门课第一讲写的东西。

| | |
|---|---|
| 仓库 | https://github.com/karpathy/nn-zero-to-hero |
| 视频 | YouTube 搜 "Neural Networks: Zero to Hero"（国内直连不通，见下面的替代方案） |
| 语言 | 英文（语速慢，有字幕） |

**课程顺序**（每讲都配一个 GitHub 仓库）：

| 讲次 | 内容 | 对应我们的项目 |
|---|---|---|
| 1 | **The spelled-out intro to neural networks and backpropagation: building micrograd** | ★ **就是你的 `engine.py`** |
| 2 | The spelled-out intro to language modeling: building makemore | 字符级语言模型入门 |
| 3 | Building makemore Part 2: MLP | 对应你的 `nn.py` |
| 4 | Building makemore Part 3: Activations & Gradients, BatchNorm | 训练稳定性的核心 |
| 5 | Building makemore Part 4: Becoming a Backprop Ninja | ★ 手写反向传播，会让你对 `_backward` 理解上一个台阶 |
| 6 | Building makemore Part 5: Building a WaveNet | — |
| 7 | **Let's build GPT: from scratch, in code, spelled out** | ★ **就是 nanoGPT 的前身** |
| 8 | Let's build the GPT Tokenizer | 对应 minbpe |

**建议**：**先看第 1 讲**，边看边对照你写的 `engine.py`。他会讲到一些你没细想的地方
（比如为什么用 `+=`、拓扑排序怎么来的），看完你会对自己的代码有全新的理解。

## 二、★ 建立直觉：3Blue1Brown 神经网络系列

**如果你想要"动画+直觉"而不是"代码+推导"，这是最好的。**

| | |
|---|---|
| 官网 | https://www.3blue1brown.com/topics/neural-networks |
| **B 站中配版** | https://www.bilibili.com/video/BV1KtM16cEDZ/ （实测可访问） |
| B 站主页 | https://m.bilibili.com/space/88461692 |

**四集结构**：

1. **But what is a neural network?** —— 用「手写数字识别」讲网络在干什么
2. **Gradient descent, how neural networks learn** —— ★ **梯度下降的几何直觉**
3. **What is backpropagation really doing?** —— ★ 反向传播在算什么
4. **Backpropagation calculus** —— 链式法则的严格推导

**为什么推荐它**：你现在缺的正是**几何直觉**——
「梯度是什么方向」「为什么损失能下降」「决策边界为什么是曲线」，用动画看一遍比读文字快十倍。

**建议**：看第 2、3 集，然后回来重读你的 `notes/05-神经网络与训练原理.md`。

## 四、边看边写代码：动手学深度学习（d2l.ai）

**李沐等人写的开源教材，中文，每章都有可运行的代码。**

| | |
|---|---|
| 中文在线版 | https://zh.d2l.ai/index.html （实测可访问） |
| 配套视频 | B 站搜「李沐 动手学深度学习」 |

**和你的项目的区别**：d2l 用的是 PyTorch 高级 API（`nn.Linear` 之类），
而你是从零手写。两者互补：

| | d2l | 你的 micrograd |
|---|---|---|
| 视角 | 怎么**用**框架 | 框架**内部**怎么工作 |
| 速度 | 快（直接调 API） | 慢（纯 Python 标量） |
| 适合 | 学怎么解决实际问题 | 学原理 |

**建议**：等你做完 micrograd，看 d2l 的「线性回归」「Softmax 回归」两章，
会发现那些 API 你已经在底层实现过了，理解会深很多。
