## 步骤 1：Value 骨架

### 要做什么

定义 `Value` 类，能存一个数，并记住「我是怎么被算出来的」。

### 为什么这样设计

自动求导的核心是**把计算过程记下来**。PyTorch 的 `Tensor` 之所以能 `.backward()`，
是因为它内部维护了一张计算图。我们用最朴素的方式：**每个 Value 记住自己的父节点**。

```
    a (叶子)      b (叶子)
      \           /
       \         /
        out = a + b     ← out._prev = {a, b}
```

### 骨架

```python
class Value:
    """存一个标量值，并记住它是怎么被算出来的。"""

    def __init__(self, data, _children=(), _op=''):
        # TODO: 存 data
        # TODO: grad 初始为 0.0（注意是 float，不是 int）
        # TODO: _backward 先设成一个什么都不做的函数
        #       （叶子节点没有上游，反向传播走到它时不用做事）
        # TODO: _prev 存 _children 的集合
        # TODO: _op 存运算名，只用于调试

    def __repr__(self):
        return f"Value(data={self.data}, grad={self.grad})"
```

  （提示：`backward()` 里会调用它，如果是 `None` 会怎样？）

## 步骤 2：前向计算（运算符重载）

### 要做什么

让 `Value` 支持 `+ - * / **`、取负、`relu`。

### 为什么这样设计

每个运算都做**三件事**：

```python

    # ① 前向：算结果值，并把父节点记下来
    out = Value(self.data + other.data, (self, other), '+')

    # ② 反向：定义「梯度怎么从 out 传回 self 和 other」
    def _backward():
        # TODO: out.grad 要分多少给 self？给 other？
        ...

    # ③ 挂上反向规则并返回
    out._backward = _backward
    return out
```

### 每个算子的局部导数（自己推一遍再写）

| 运算 | `out` | ∂out/∂self | ∂out/∂other |
|---|---|---|---|
| `self + other` | `a + b` | 1 | 1 |
| `self - other` | `a - b` | 1 | **-1** |
| `self * other` | `a * b` | `b.data` | `a.data` |
| `self / other` | `a / b` | `1/b` | `-a/b²` |
| `self ** n` | `a^n` | `n * a^(n-1)` | — |
| `relu(self)` | `max(0,a)` | `1 if a>0 else 0` | — |

### 关键技巧：不要重复实现

```python
def __neg__(self):      return self * -1
def __sub__(self, other):   return self + (-other)
def __rsub__(self, other):  return other + (-self)
def __truediv__(self, other):   return self * other ** -1
def __rtruediv__(self, other):  return other * self ** -1
```

**只实现 `__add__`、`__mul__`、`__pow__` 三个「原语」，
其余全靠组合。** 这样代码量少，也不容易出错。

### 镜像方法（`__r*__`）的坑

Python 里 `1 + Value(2)` 会先试 `int.__add__(1, Value(2))`，
失败后调 `Value(2).__radd__(1)`。所以：

```python
def __radd__(self, other):  return self + other      # 交换律，无所谓顺序
def __rmul__(self, other):  return self * other      # 交换律，无所谓顺序
def __rsub__(self, other):  return other + (-self)   # ★ 必须是 other - self
def __rtruediv__(self, other): return other * self**-1  # ★ 必须是 other / self
```

`__rsub__` 写反的话，`3 - Value(2)` 会得到 `-1`。

### 还要处理「other 是普通数字」

```python
def __add__(self, other):
    other = other if isinstance(other, Value) else Value(other)
    ...
```

否则 `Value(2) + 3` 会报 `AttributeError: 'int' object has no attribute 'data'`。

## 步骤 3：单节点反向传播

### 要做什么

实现 `backward()`，让最简单的 `c = a + b` 能算出 `a.grad`、`b.grad`。

### 核心：链式法则

```
∂最终输出/∂a = ∂最终输出/∂c × ∂c/∂a
                ↑ 这就是 out.grad      ↑ 这就是局部导数
```

所以每个 `_backward` 做的事是：

```
self.grad  += 局部导数(self, other) × out.grad
other.grad += 局部导数(other, self) × out.grad
```

### ★ 最容易错的：`+=` 而不是 `=`

```python
self.grad += out.grad      # ✅ 累加
self.grad  = out.grad      # ❌ 覆盖
```

**为什么必须累加**：一个节点可能被用到多次。比如 `b = a * a`，
`a` 同时是左操作数和右操作数：

```
db/da = ∂(a*a)/∂a(左边) + ∂(a*a)/∂a(右边) = a + a = 2a
```

### `backward()` 的骨架

```python
def backward(self):
    # TODO: 用后序 DFS 构建拓扑序 topo
    #       提示：递归遍历 _prev，访问完所有孩子后再把自己 append
    # TODO: 种子梯度 self.grad = 1
    # TODO: 逆序遍历 topo，依次调用 v._backward()
```

**为什么需要拓扑排序**：看菱形依赖

```
    a
   / \
  b   c
   \ /
    d
```

`d` 的梯度要同时传给 `b` 和 `c`，而 `b`、`c` 的梯度**必须先都算完**才能正确传给 `a`。
后序 DFS 保证「一个节点被 append 时，它的所有孩子已经在 topo 里了」，
所以 `reversed(topo)` 就是正确的处理顺序。

**为什么 `self.grad = 1`**：最终输出对自己的导数是 1，这是整条链式法则的种子。

## 步骤 4：链式法则（多层 + 菱形）

### 要做什么

其实步骤 3 做完，步骤 4 应该自动通过——如果你正确实现了拓扑排序和累加。

### 手推验证

题目：`d = a*b + b**3`，`a = -4, b = 2`

```
前向：d = (-4)(2) + 8 = -8 + 8 = 0

∂d/∂a = b = 2                    （只有 a*b 这一项含 a）
∂d/∂b = a + 3b² = -4 + 12 = 8    （a*b 给 a，b³ 给 3b²）
```

菱形：`b = a+1, c = a*3, d = b*c`，`a = 2`

```
b = 3, c = 6, d = 18
∂d/∂a = ∂d/∂b × ∂b/∂a + ∂d/∂c × ∂c/∂a
      = c × 1 + b × 3 = 6 + 9 = 15
```

**如果这一步失败，几乎肯定是**：
- 拓扑排序顺序错了（应该逆序遍历）
- 或者梯度用了 `=` 而不是 `+=`

## 步骤 6：数值梯度验证

### 要做什么

也不用改代码。用**有限差分**独立验证梯度：

```
∂f/∂a ≈ [f(a+ε) - f(a-ε)] / (2ε)
```

这个方法不需要任何自动求导，纯粹靠定义。如果它和你的解析梯度一致，
说明你的实现是对的。

**这是「双重验证」**：PyTorch 是「另一个实现」，数值微分是「数学定义」。
两条独立路径都对上了，可信度就很高了。

## 常见卡点速查

| 现象 | 原因 |
|---|---|
| `AttributeError: 'int' object has no attribute 'data'` | 忘了把 `other` 转成 `Value` |
| `3 - Value(2)` 得 `-1` | `__rsub__` 顺序写反 |
| 梯度是 0 | `backward()` 里忘了 `self.grad = 1` |
| 梯度小了整数倍 | 某个 `_backward` 里漏了一项 |
| 共享节点梯度不对 | 用了 `=` 而不是 `+=` |
| `RecursionError` | 拓扑排序没记 `visited` |

更多见 `notes/03-常见错误对照表.md`。
